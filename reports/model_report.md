## Models

### 1. Workout classifier — `artifacts/workout_model.joblib`
- RandomForest (80 trees, max_depth 12): compact config chosen — identical test
  metrics to a 400-tree config with ~10x smaller artifact.
- Features (8): `Age, Weight_kg, Height_cm` numeric + `Gender, Goal, Equipment,
  Experience, Injury` one-hot (unknown → ignored).
- Target (24 classes): `Recommended_Plan`.
- Report (metrics/workout_metrics.json): test accuracy vs most-frequent dummy baseline.

### 2. Diet regressor — `artifacts/diet_model.joblib`
- RandomForest multi-output regressor (80 trees, max_depth 12).
- Features (7): `Age, Height, Weight` + `Gender, Activity Level, Fitness Goal,
  Dietary Preference` one-hot.
- Targets (4): `Daily Calorie Target, Protein, Carbohydrates, Fat`;
  per-target MAE and R² vs mean-baseline in metrics/diet_metrics.json.

### 3. Food KNN — `artifacts/knn.joblib`
- StandardScaler + NearestNeighbors over Anuvaad per-100 g columns
  `energy_kcal, fat_100g, carbs_100g, sugars_100g, fiber_100g, proteins_100g,
  sodium_100g`; query vectors are the documented goal reference profiles
  (ml/config.py `GOAL_NUTRITION_TARGETS`).
- **No allergen columns ship with Anuvaad** → flags are DERIVED from food
  names by explicit keyword rules (`ml/allergens.py`, Indian/English/French
  vocabulary, exceptions such as coconut/soy/almond milk and "eggless",
  optional plural suffixes). At the current retrain 425/1,014 foods carry ≥1
  flag (gluten 214, dairy 167, eggs 41, fish 23, peanuts 15, nuts 12,
  soy 10). Flagged foods are excluded from KNN ranking and meal suggestions
  are screened the same way. "Not flagged" is never a certified
  allergen-free guarantee; every allergy-filtered response repeats this.

### 4. Plan layout — `ml/plan_layout.py`
The model predicts plan NAMES only. The layout into day-by-day exercises:
- every one of the 24 plan classes is mapped (asserted at train time) to an
  ordered body-part rotation, supported equipment labels, and a fixed
  (sets, reps) scheme — see `PLAN_LAYOUTS`;
- exercises come ONLY from `datasets/exercises.json`, filtered by body part +
  user-selected equipment; deterministic order, first 5 per day;
- session minutes are a documented heuristic (warmup 5 + exercises x sets x
  (reps x 3 s + 60 s rest)) — no per-plan durations exist in any dataset.

## Honesty notes carried into every API response
- The workout model is a classifier: probabilities are model beliefs, not
  accuracy; equipment-constrained decoding never rescores plans.
- Macro predictions are model outputs with reported MAE — informational, not
  medical advice.
- Meal suggestions are retrieved rows from the nutrition dataset, never
  generated, and are not allergy-screened.
- Duration estimates are labeled heuristics everywhere they appear.

`reports/sample_unified_response.json` is a real end-to-end response captured
from the artifacts (not mock data).
